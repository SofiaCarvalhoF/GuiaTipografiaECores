# 🎨 Identidade Visual — Banco Itaú

Repositório criado para documentar e padronizar o **Design System / Guia de Estilo (Tipografia e Cores)** do Banco Itaú, que serve como base para todos os projetos e trabalhos do curso.

---

## 📌 Sobre o Projeto

Este guia de estilo foi desenvolvido utilizando o **Figma** a partir do modelo disponibilizado pelos professores. O objetivo é garantir consistência visual e acessibilidade no desenvolvimento de interfaces das nossas aplicações.

* **Orientadores:** Prof. Raul & Prof. Denani
* **Ferramenta:** Figma
* **Fonte Padrão:** Poppins
